# 全局分支库 / 问题库 / 知识库 字段与关系速查

## 三层关键词来源（判定时按此优先级取）

```
1. 本地 answerKeywordDef          （话术包自写，最优先）
2. answerRegexSide 指定的全局具名分支   （关键！见下）
3. 全局库同名分支（仅当 1、2 都为空时退化使用）
```

## answerRegexSide

节点/分支上的 JSON 字符串字段，声明"本地分支名 → 引用的全局库具名分支列表"：

```json
{"肯定": ["省厅-肯定（中性）", "肯定(中性)", "肯定（西湖-有下载）"],
 "否定": ["否定（中性）", "否定（没点过或没登录过）"]}
```

坑：
- 本地分支名 ≠ 全局分支名。宜昌劝阻的"肯定"实际用的是 `省厅-肯定（中性）` 等，
  全局库里叫"肯定"的 4 个分支（ID 21/53/118/3910）反而一个都没被引用。
- `answerRegexSide = ''`（空字符串）表示"无外部引用"，不是"用同名分支"。
- 字段挂在**决策树每一层**（decisionNodeBO 与每个 childrenList 元素都有），
  取词时要按层取，不要只看顶层。

## 全局分支库（branches_raw.json / detail）

| 字段 | 含义 | 坑 |
|---|---|---|
| id | 分支 ID | **同名分支可能有多个**（如"肯定(中性)"有 110/376 两个），改动必须精确到 ID |
| name | 分支名 | 同名跨场景很常见（政务测试/居住登记核查/移动满意度…）|
| keywordList[].keyword | 正则，逐条 | 含百应方言 `{0<>N}`、变长 lookbehind |
| botSceneNames | 关联场景（list） | 判断同名分支属于哪个场景的关键 |
| keywordNum | 关键词数 | 与 keywordList 实际数一致 |

## 全局问题库（questions_raw.json / detail）

同分支库，`name` 字段换成 `standardQuestion`。
问题库条目 ~128 条 / 1,012 条正则；分支库 ~327 条 / 2,421 条正则。

## 话术包知识库（bundle.knowledgeBase[]）

| 字段 | 含义 | 坑 |
|---|---|---|
| standardQuestion | 标准问法 | 是**意图描述**（"市民表示亲戚朋友被骗"），不是用户原话 |
| similarityQuestion | 相似问法 | **常是字符串 `"[]"`（脏数据）**，必须视为空，不能 split |
| keyword | 触发正则 | 可能是空字符串 `""` / `"[]"`，也可能 list |
| action / actionParam | 命中后动作 | action=3 时 actionParam.sceneNodeName 是目标节点 |
| answerList[].knowledge | 命中后的话术 | — |

### 死条目判定

```
无 keyword（或空串/[]/null）且 无有效 similarityQuestion  → 永远不可能命中
其中配有 target（action=3）的 → 最严重：配了去向却走不到
```

实测：2161410 有 78/99 条死条目（79%），其中 36 条配了去向。
290 条知识库中 127 条死条目、68 条配了去向。

## 知识库匹配的正确姿势

```js
// 正则优先
for (const re of entry.res) if (re.test(text)) return hit;
// 相似问法：只做正向包含（用户话术包含意图词）
for (const n of entry.norms)
  if (t === n || t.includes(n)) return hit;
// 禁止反向包含（n.includes(t)），否则"我在"会命中一切短句 → 19 万虚假命中
```

```js
          证件|工号|派出所|公安局|再说一遍|听不清|听不到)/

```

## 通话记录侧

- dialogue_turns.jsonl 每行 `{id, turn, role, text}`
- AI 空转写约 14%（131,635/916,378），判定时跳过
- 系统提示音（"您好。在吗"/"条件判断-条件判断节点"）约 5%，建立 SYS 正则排除
- **无节点轨迹字段**：节点序列靠 AI 话术精确匹配反推（规则版话术写死 → 命中率 94.9%）
