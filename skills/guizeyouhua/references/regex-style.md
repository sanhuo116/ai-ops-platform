# 库内正则写法范本（V8 方言）与改写规范

> 来源：用户提供的全局库真实正则 6 条 + 2251810 实战改写全量回归。
> 优化正则必须**先学这些写法**，按同风格产出，再用全量语料回归验证。

## 一、范本 6 条（原样，勿改）

```
(?<![没不么无否未木].{0,8})有[一两三四几12345].{0,1}[个次]
(?<!(没|不|现))在[呢呀啊的](?!.{0,8}[哪没])
(?<!(不|没|哪里|怎么|如何|咋).{0,4})(对的|可以)(?!.{0,5}处理)
(?<!([没不么无否未木]|哪里|怎么|如何|咋).{0,4})会(留意|注意|谨慎)
(?<!(不|无|没).{0,10})有过
^[^(不|没|别)]*(记得)
```

## 二、库风格要素（从范本提炼）

| 要素 | 范本出处 | 用法 |
|---|---|---|
| **否定词族 lookbehind** | `(?<![没不么无否未木].{0,8})` | 单字否定族用字符类；多字否定（哪里/怎么）用 `(a\|b)` 交替 |
| **限量间隔 `.{0,N}`** | 同上 | lookbehind 里必须带间隔，否则拦不住隔字否定（"他没说过有3次"）|
| **后向排除 lookahead** | `(?!.{0,5}处理)` | 命中词后面不能跟的是疑问/否定延续 |
| **`.{0,1}` 柔性分隔** | `有[一两三四几12345].{0,1}[个次]` | 词与量词之间允许 1 个插入字，比硬锚定召回高 |
| **`^[^(不|没|别)]*` 前缀过滤** | `^[^(不|没|别)]*(记得)` | 句首锚定+前缀字符类过滤（注意：字符类里的 `\|` 是字面量）|

**方言警告**：范本全是 V8 语法（变长 lookbehind）。Python `re` 编译会报
`look-behind requires fixed-width pattern`，必须用 Node/V8 验证（skill 已有此条认知）。

## 三、实战改写对照（2251810 全量语料回归）

### R1 人工（82 → 87，+5 -0）
```
旧: (转|找|要|请|帮我|给我).{0,3}人工|人工(服务|客服|坐席)|真人(客服)?|接(人|客服)|客服人员
新: (?<!需)(?<!不用)(?<!别)(转|找|要|请|帮我|给我).{0,3}人工
   |(?<!(需要|不用|先不|别).{0,2})(?<!不是)(?<!还是)(?<!是)人工(服务|客服|坐席|吗|呗|哈)?
   |真人客服?|客服人员
```
- 新增裸"人工。"、"就系人工。"、"人工语音。"（放宽了尾缀）；
- lookbehind 拦"不需要人工/不是人工/你是人工还是"；
- **动词消耗陷阱**：动词分支的否定前缀若以动词本身结尾（"不需要"的"要"），
  lookbehind 拦不住（动词被 Y 消耗）→ 语料无此形态时**不加约束**，宁缺毋滥。
- **多字否定的窗口**：`(?<!(需要|不用|先不|别).{0,2})` 的 `.{0,2}` 让 lookbehind
  从更早起点匹配（覆盖"需+要(动词)"整体）——这是范本 `.{0,8}` 的精髓。

### R2 多张（39 → 40，+1 -0）
```
旧: (?:^|[。，,！？?\s])[二两三四五六七八九\d]张|好几张
新: (?:^|[。，,！？?\s])[二两三四五六七八九\d].{0,1}张|好几张
```
- 学范本 `有[一…].{0,1}[个次]`：数字与"张"之间允许 1 个插入字（"30张"）。

### R3 数字词（3 → 3）
```
^(一|幺|壹)[的呀啊哈嘛吧]?[。，,！？?]?$   （2/3/4/5/0/9 同构各一条）
```
- 单字键值无可加否定约束，保留锚定（范本第 6 条同风格）。

### R4 确认词（501 → 518，+64 -47）
```
旧: ^(嗯|嗯嗯|对|对对|对对对|是的|是|对呀|是的呀|好|好的|嗯对|哦|哦哦|啊|对的|是呀)[的呀啊呢哈嘛吧]?[。，,！？?]?$
新: (?<![你您].{0,6})(?<![不没别甭].{0,2})(?<![这就要还但].{0,2})
   (嗯+|对+|(?<!工|分|师)是的?|是呀|对呀|好的?|嗯对)(?!吧)[的呀啊呢哈嘛吧]?[。，,！？?]?$
```
- 放开句首锚定（混合段尾"嗯，是的。"可命中），用否定词族 lookbehind 保安全：
  - `(?<![你您].{0,6})` 拦"你好/您好/…您这边是"（问候尾"好/是"）
  - `(?<![不没别甭].{0,2})` 拦"不是/不对/不好"
  - `(?<![这就要还但].{0,2})` 拦"这是/就是/要是/还是/但是"尾
  - `(?<!工|分|师)是的?` 拦陈述残句"指纹工是/分是"
  - `(?!吧)` 拦求证"是的吧/对吧"（丢失"对吧/是吧"是**语义修正**，不是缺陷）
- 丢失 47 条 = "哦。x14 啊。x27 对吧/是吧/好吧 x5"：语气词与求证词，核实语境本就该弱化。

### R5 否认（5 → 6，+1 -0）
```
旧: ^(没有|没被?冻结|不用了?|不需要|没办过|不是我的|没开通)[。，,！？?]?$
新: (?<!要是.{0,4})(?<!要.{0,4})(?<!最好.{0,6})(?<!有)(?<![了结好成完办到说].{0,6})
   没有[的呀啊嗯哈嘛吧]?[。，,！？?]?
   |(?<!要是.{0,4})(?<!要.{0,4})(?:没被?冻结|不用了?|不需要|没办过|不是我的|没开通)[的呀啊嗯哈嘛吧]?[。，,！？?]?$
```
- 放开锚定后混合段尾"没有"出现（"没有，我得去操作"）——但这正是想要的（答句带尾语）；
- `(?<!有)` 拦"有没有啊？"疑问；`(?<![了结好成完办到说].{0,6})` 拦"结束了没有？/弄好了没有"
  （动词性反问，不是否认答句）。
- **教训**：放开锚定必须在 lookbehind 里补齐动词性前缀排除，否则"我话没有讲完呢"全放进来
  （中途版 17 命中里 11 条误报，靠动词族 lookbehind 收回）。

## 四、改写五步法（每次优化都走）

1. **学范本**：先看库内同场景正则的写法（否定族、间隔、锚定习惯）。
2. **放开该放开的**：锚定过死导致漏召回（混合段尾）时，去 `^` 改 lookbehind 守门。
3. **每放一处，补一处否定排除**：`(?<![不没别甭].{0,N})` + 动词性前缀族 + `(?!吧)` 类后向。
4. **V8 全量回归**：旧式 vs 新式的 +增/-减逐条核对语义（新增必须是目标意图，丢失必须可解释）。
5. **边界集固化**：把"你好。/不是。/不需要人工。/结束了没有？"这类边界写进断言清单，回归必跑。

## 五、必须记住的三个陷阱

1. **动词消耗陷阱**：否定前缀以动词本身结尾（"不需要"的"要"、"别转"的"转"），
   lookbehind 拦不住——动词被命中词消耗。语料无此形态时不加约束（宁缺毋滥）；
   语料有此形态时改用变长 lookbehind 覆盖"否定词+动词"整体。
2. **lookbehind 是紧邻语义**：`(?<!需)` 只拦"需"紧邻的下一个字；拦"隔字否定"必须带 `.{0,N}`。
3. **contains 复核的假阳性**：全量验证时"命中句含否定字"≠"命中点是否定语义"，
   必须用 `exec` 看真实命中点再判。
